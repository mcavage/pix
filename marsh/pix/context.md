# Pix on marsh

This is upstream Pi with the public Pix package. marsh owns child processes,
isolation, split/fanout, cancellation and receipts. No old Pix launcher, custom
subagent runner, Docker hosted model gateway, or memory service is installed.
Use the marsh-orchestration skill for role work orders and composition.

Personal config is ~/.pix-agent/agent. Public skills/roles are in
/opt/pix/package. Business skills/MCP are optional private, host-owned additions,
never shipped in this Kit. Discovery/role labels do not prove model identity or
permissions. Follow the actual job context and inspect returned evidence.
