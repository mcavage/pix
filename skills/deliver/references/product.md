# Product delivery entry point

For a new product or material feature, use [product agreement](product-agreement.md):
PR/FAQ, PRD and architecture before implementation, with existing approval and
explicit autonomy preserved. Continue through [deliver](../SKILL.md), using
[verification](verification.md) and [independent review](review.md) on the combined
product. Optional specialists resolve named uncertainties; this reference does not
add a mandatory product, architecture, QA or security crew.

Keep the original user journey as the acceptance target. Distinguish product
acceptance, workflow completion and authorized release (local artifact, PR or
deployment). An author report or green unit suite is not executed journey evidence.
